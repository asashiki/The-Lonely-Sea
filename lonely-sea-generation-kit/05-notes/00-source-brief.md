# 原始需求摘要

项目名：**孤独之海**

用户给出的方向：

- 美术基调取自 `恋狱/孤独之海` 资料夹。
- 固定场景为安静、空旷的海边沙滩。
- 初始主色为灰朦胧。
- 后续需要晴天、暗夜和黑血红深夜三种场景状态。
- 未来左侧可能放入不露脸、撑太阳伞的 Live2D 少女。
- 右侧安排无明显容器的纵向 Galgame 菜单。
- 背景应简单、克制，突出人物和界面，而不是成为复杂的概念场景。
- 网页端再叠加雪、雨等实时渲染，不要把粒子烘焙进背景图。
