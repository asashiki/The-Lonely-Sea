# 「孤独之海」图像生成资料包

这是一份可继续迭代的归档，保存了 2026-07-17 生成的四张「孤独之海」场景图、实际输入给图像生成工具的参考图、完整提示词、流程记录和文件校验信息。

## 核心流程

```text
三张构图/画风参考图
        ↓
生成灰雾母版（同时也是第一张成品）
        ├── 灰雾母版 + 晴天色彩参考 → 晴天
        ├── 灰雾母版 + 夜晚色彩参考 → 暗夜
        └── 灰雾母版 + 深红色彩参考 → 黑血红深夜
```

四张图不是各自独立重画。后三张都把灰雾图作为第一输入，要求锁定机位、海岸线、地平线和浪线，只改变光照、天空与色彩。这是四张图具有同一地点感的关键。

## 文件夹内容

- `01-final-images/`：四张最终成品。
- `02-reference-images/used/`：六张实际传入生成工具的参考图。
- `02-reference-images/considered-not-used/`：需求阶段提到、但最终没有传入工具的少女氛围图，避免以后误认为它参与了生成。
- `03-intermediate-images/`：灰雾母版的独立副本；它既是成品，也是后三张图的中间输入。
- `04-prompts/`：四次任务实际使用的完整提示词，以及复现步骤。
- `05-notes/`：原始需求、设计判断、参考图分工、技术与来源记录。
- `manifest.json`：面向 Agent 或脚本读取的结构化流程清单。
- `SHA256SUMS.txt`：所有 PNG 的 SHA-256，用于检查归档是否被改动。

## 如何继续生成同系列图片

1. 选择 `03-intermediate-images/01-master-mist-used-for-edits.png` 作为第一输入。
2. 再加入一张只负责新时段、天气或色彩语言的参考图。
3. 复制 `04-prompts/02-day-edit.txt` 一类编辑提示词。
4. 只修改状态名称、光色描述和第二参考图；保留“锁定构图”和负面约束。
5. 生成后检查海岸线、地平线、浪线及左右留白是否仍与母版一致。

本次使用的是 Codex 内置 `image_gen` 路径，没有使用 CLI、API Key、透明背景流程或本地后期调色。工具没有提供可归档的 seed，也没有暴露稳定的底层模型版本参数，因此资料包能复现方法、构图与画风方向，但不能保证逐像素复现。

关于用户要求的“思考过程”：`05-notes/01-process-and-rationale.md` 记录了可公开、可复用的设计判断和取舍；不包含模型私有的逐步内部推理。
