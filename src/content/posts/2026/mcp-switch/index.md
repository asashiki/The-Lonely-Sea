MCP Switch 是一个自托管网关：本地 stdio 和远程 HTTP 的 MCP 服务可以挂到同一扇 OAuth 门后面，AI 连一次就能用上整套工具。

控制台演示在 [show.asashiki.com/console](https://show.asashiki.com/console/)，源码在 [GitHub](https://github.com/asashiki/mcp-switch)。这篇先当演示介绍。
