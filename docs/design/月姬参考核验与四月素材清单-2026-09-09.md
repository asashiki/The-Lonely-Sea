# 月姬参考核验与四月素材清单

2026-09-09。研究与制作建议，不改运行页面，不生成图片，不改剧情。

## 最新方向

用户现在选择以《月姬 remake》的 NVL 表达为主要参考。此前“两格漫画＋右侧插画”的原创方案不再是必须保留的目标；五张安娜素材保留，Q 版是否使用等实际参考与场景需要确认。本文件是对 9 月 8 日方案方向的更新，不是说已完成原作演出拆解。

## Gemini 的总结能用到什么程度

可把分屏、局部镜头、明暗改变、转场、显字节奏作为查找线索，不能直接当成已验证的月姬镜头表。缺少原视频链接，所有时间戳暂时无法复核。

- “很少单用背景”“往往有微小位移”是频率判断，需要连续观察，不能从几张截图推出。
- 红色画面不等于阈值处理；普通调色、颜色覆盖、替代图都可能形成类似结果。
- 出现模糊不等于径向模糊，更不能据此确定代码实现。
- 同一时刻文字与光影都在变化，不一定意味着二者存在同步事件。
- 3–5 帧不是可靠的时间规格，必须先确认视频帧率和实际连续帧；不能与“低于半秒”混为同一种节奏。
- 有位移不一定是多层视差；整张合成图移动、镜头裁切也可能产生类似画面。

原作的实现不可从成片完全反推。我们的任务是复现观感和阅读行为，不是猜对它用了什么内部技术。

## 哪些效果不需要用户提供素材

| 效果 | 所需输入 | 注意事项 |
|---|---|---|
| 显字、旧句退淡、句尾光标、翻页 | 字体、文本与代码 | 先从实机核对规则，不能靠多加动画代替 |
| 淡入、淡出、黑场、纯色变化 | 代码 | 不用让模型生成黑图和红图 |
| 裁切近景、横向取景、分屏 | 已有清晰图片＋代码裁切 | 换视角、换姿势不是裁切；素材分辨率不足时才补特写 |
| 局部遮暗、简单光区 | 代码或简单遮罩 | 作用到人物和背景的方式应分开控制，默认不覆盖文字 |
| 复杂树影、窗影、不规则过渡 | 可复用遮罩图 | 有具体场景需求再做，不因原作某处出现就到处使用 |
| 人物侧身、低头、坐下、递东西 | 真正的新姿态图片 | 不能靠旋转现有平面图伪造；与动作接触的道具一起画 |

若需要影子素材，交付独立透明 PNG（或用于透明度控制的灰度图）；不要混在背景里。遮罩最终作用与强度由播放器决定。四月当前没有已经验证的树下镜头，因此不要求树叶遮罩。

已有普通人物可先测试有限的脸部／手部裁切，不能保证裁大后仍清晰。先在目标画面大小查看一次，缺清晰度或缺不同表情时，再明确补哪张特写。

## 研究应当交付什么

原视频链接到位后，先核对 00:29:25–00:32:30，而不是一次研究五小时：

1. 连续观察，找出文字、人物、背景、声音实际变化的时刻。
2. 对每个变化保留前、中、后画面；小范围加密观察，而不是整段每一帧都丢给模型。
3. 每条分开记“直接看到”“可能实现”“我们准备怎样做”。
4. 区分玩家阅读等待与游戏强制等待；视频没显示输入时保留不确定性。
5. 标注现有素材足够、需要新表情、需要新视角、需要遮罩四类。
6. 做一小段可点击样段，对照参考验证。没有观察到的效果不冒充复刻。

后面再看特殊情绪镜头。高速黑白切换、持续镜头漂移和反复闪烁不应成为日记的默认表现；它们即便在原作存在，也需要匹配当前叙事情境。

## 实现边界

先做通用阅读规则与可恢复镜头状态，再增加效果。读取存档、切语言、跳过演出应恢复最终画面，不重新串行播放所有入场。未知影像访问情况不能包装成已经观看；目前仍需要原视频 URL 来验证 Gemini 的时间戳。

技术参考只是说明可能的实现方式，不证明月姬用了相同技术：

- [Ren’Py Transitions](https://www.renpy.org/doc/html/transitions.html)：淡化、裁切转场和基于控制图的转场彼此不同。
- [Ren’Py Layered Images](https://www.renpy.org/doc/html/layeredimage.html)：图层组合需要对应素材，不自动产生姿态或新视角。
- [Ren’Py NVL Mode](https://www.renpy.org/doc/html/nvl_mode.html)：叙述与角色话语可使用 NVL 阅读形式，不要求角色说话时改为 ADV。

项目继续使用自研播放器，不迁移引擎。
