# NVL 后续制作：一手资料与适用边界

日期：2026-09-08。仅资料研究；共 6 个一手来源。项目沿用自研 Astro，Ren’Py 仅作概念参考。

## 1. Marco & The Galaxy Dragon：CG 与卡通动画并用

[TOKYOTOON 作品官方网站](https://uyragnigotocr.am/)

- 可支持：官网 STORY 区明确介绍原创动画与“CG・スチル1000枚級”；角色区同时标注リアル／カートゥーン版本；提供 MOVIE、GALLERY，并公告体验版及 OP 发布。因此“大量静态图像＋卡通动画＋不同角色表现版本”确有官方依据。
- 不支持：千张级不等于千张独立构图；官网未解释差分计数、镜头频率、制作成本或资产复用率。卡通动画也不能直接等同于漫画分格或 Q 版静态格。本次未播放影片或体验游戏，不能据此声称看过具体演出。
- 本项目推论：可以给关键情绪准备独立构图、普通／夸张反应版本与少量动画段；数量应由分镜需求决定，不能把千张级当生产指标。

## 2. 魔法使いの夜：官方体验资源与制作分工

[TYPE-MOON 官方产品页](https://typemoon.com/products/mahoyo/product/)

- 可支持：官方页列出 PS4／Switch 体验版入口并说明体验版已发布；制作名单单列“演出・スクリプト”，与背景美术、原画、程序、音乐并列。可将其作为后续实际观察游戏演出的正规入口，并确认演出脚本是明确的制作职能。
- 不支持：产品页不是逐镜头分析；不能从制作名单推断具体转场、镜头时长、文本覆盖方式或内部技术。本次仅核读页面，未下载试玩、未播放视频，也未确认各地区商店当前可用性。
- 本项目推论：分镜应同时写图像、文字推进与声音事件；美术清单之外需要演出编排。本轮不将“月姬／魔夜级演出”写成已验证的实现标准。

## 3. Ren’Py Layered Images：角色差分组合

[Layered Images 官方文档](https://www.renpy.org/doc/html/layeredimage.html)

- 可支持：用基础层、属性与分组组合多张图像，避免为衣服、发型、表情的所有组合分别导出完整图片；支持默认属性、条件层与组内替换。
- 不支持：分层不会自动生成新姿势、视角或正确的人体结构；文档不能保证 Astro 的内存与加载表现。
- 本项目推论：同姿势差分采用统一画布、锚点与图层命名；换姿势、换机位仍应视为另一套资产。

## 4. Ren’Py Text：文字本身参与演出

[Text 官方文档](https://www.renpy.org/doc/html/text.html)

- 可支持：`cps` 控制局部显字速度；`w` 等待点击或指定秒数；`p` 结束段落并等待；`nw` 行末自动继续；`clear` 可清除 NVL 文本页。
- 不支持：这些标签不是 Astro 现成语法，也没有给出适合所有语言的最佳速度；标签存在不证明当前项目已支持相关交互。
- 本项目推论：将局部停顿、段落结束、翻页与自动推进设为显式脚本事件。具体数值应服从中文阅读与场景节奏。

## 5. Ren’Py Audio：声道与播放语义

[Audio 官方文档](https://www.renpy.org/doc/html/audio.html)

- 可支持：普通声道支持播放／排队，单声道一次播放一个文件；可注册新声道；特殊 `audio` 声道可叠播；支持淡入淡出、循环和 `if_changed`，避免相同曲目重复启动。
- 不支持：Ren’Py API 不能直接用于浏览器；多声道本身不保证无缝循环、同步与最终混音质量。
- 本项目推论：区分 BGM、环境循环、一次性音效和语音的职责，明确切景时哪些继续、替换或停止；需要叠加环境声时设独立声道。

## 6. Ren’Py Rollback：恢复完整阅读状态

[Saving, Loading, and Rollback 官方文档](https://www.renpy.org/doc/html/save_load_rollback.html)

- 可支持：rollback 可理解为在交互语句起点保存状态、回退时恢复；状态包含当前语句、显示图像／界面、音乐及 NVL 文本块。
- 不支持：它不等同于只减文本索引，也不是每一动画帧的录像；不能据此保证浏览器任意音频、计时器或外部副作用会自动恢复。
- 本项目推论：若扩展回退，应定义可重建的阅读检查点：段落位置、画面／角色属性、文字页与持续音轨。一次性音效是否重播要单独规定。

## 对制作方案的约束

以上资料支持“按叙事需要组织多种画面、把文字和声音写入演出脚本、以可恢复状态管理播放”的方向。它们不提供本项目所需 CG 张数、动画预算或画师提示词配方；这些仍需由项目现有分镜和样段决定。
