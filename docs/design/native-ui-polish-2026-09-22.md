# 通讯与设定页：原生交互打磨

沿用已确认的页面分类与海面，不另加组件库或动画运行时。

- OPTION 的游戏文字、博客阅读页增加真实字号/行距预览；拖动对应设置、切换语言和恢复默认值时同步。样张采用站名，不新增角色台词。
- 友链页加入可展开的本站资料，复制名称、网址与介绍。剪贴板不可用时选中文本供手动复制；友链名称已等于域名时不重复显示域名。
- 留言输入使用原生 `field-sizing: content`，设置上下限，长文不会撑满整个游戏窗口。不支持时保留原有可调整大小的输入框。
- 使用 `@starting-style` 做 160ms 的内容入场，离场仍立即隐藏，避免旧页面挡住操作。减少动态偏好同时覆盖系统设置和网站设置。
- 表单通过容器查询按实际可用宽度排列提交动作；触屏上的设置控件保持 44px 最小点击高度。
- 标题采用平衡换行，说明采用更自然的换行。友链外跳箭头和按压反馈只做很小的位移。

技术依据（官方资料，2026-09-22 查阅）：

- https://developer.chrome.com/docs/css-ui/css-field-sizing
- https://developer.chrome.com/blog/entry-exit-animations/
- https://web.dev/articles/prefers-reduced-motion

这些是当前可使用的原生能力，不宣称它们都是今年才发布的特性。通过渐进增强保留旧浏览器功能。预览浏览器访问 asashiki.com/connect/ 返回 502，未将本轮构建/DOM 检查当作真实浏览器截图验收。
