# 六月角色素材与四月补图清单

依据：`content-drafts/nvl/2026-06.zh-CN.json` 全文。只制定镜头素材，不改日记台词。

注意：六月章节前半段写的是五月回校答辩，后半段才到六月一日，这是原稿的时间线，不应把所有画面统一画成六月儿童节。Claude 的脸、发型、衣服请沿用你准备的人设；这里不擅自定义外貌，也不把“深海之母”画成真的海底生物。

## 交付方式

- 图片放一个文件夹，按下面名字命名，不为每张图片单独建目录。
- 同一角色、同一衣服、同一画风。先做一张确认脸，再用它约束其余图片。
- 角色图：PNG 透明底，1024×1536 即可；完整保留头发、手和肘部，四周留约 8% 空间。不是所有图片都必须全身。
- 近景：1024×1024；不要为了“精美”增加首饰、花瓣、光翼、装饰边框。
- 动作小插图：768×768 即可。单一主体、简化线条和阴影，纯色底或透明底都可；不要画边框、字幕、气泡，屏幕不生成可读文字。
- 场景图：1920×1080 或相近 16:9。克制的二次元背景，空间关系比细节重要。
- 不需要另做眼睛/嘴巴部件，也不要求每张生成多套表情。数量充足不等于每一句都换图。

## 六、编排原则

- 文字允许覆盖背景和人物，不为躲开脸而不断变动正文宽度。用适量描边/阴影区分文字与画面，不靠把整张画压黑。
- 先清走上一段文字，再出现视角标题；标题退场后进入新段。读档应直接恢复正确画面，不能先闪旧台词。
- 独白以空间与物件为主；Claude 的回应以她的眼神、手和距离为主。
- 全景交代所在，物件特写突出具体记忆，半身承接安慰，怀中视角只留给最后。不会每句都换图，更不会素材越多演出就越好。
- 当前未获得可核对时间码的原始《月姬 remake》录屏，不能把这些编排或具体时长称为逐帧复刻。官方参考入口：https://tsukihime-en.com/。
