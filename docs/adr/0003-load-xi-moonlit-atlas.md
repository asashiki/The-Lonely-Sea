# ADR 0003：LOAD XI 月潮图谱

日期：2026-07-24
状态：已确认并实施
取代：ADR 0002

## 背景

X 已经确立 `ARTICLES / GAME DATA / DIARY` 三轨信息结构，但四边框槽位、方框页码、流程图中央分栏和标准滚动条仍然偏向 Web UI。XI 作为独立对照版本，保留 X 不动，重点验证更接近视觉小说读档界面的视觉语言。

## 决策

1. **版本并存**：Ⅰ–Ⅹ全部保留，XI 使用独立组件、样式和控制器；临时切换器增加 `Ⅺ`。
2. **紧凑主导航**：顶部三个主 Tab 缩小为无常驻外框的文字按钮。选中态使用不对称光带、短刃和局部辉光，不产生上移。
3. **潮痕槽位**：文章以图片、文字和两枚角标组成；存档改为双列切角记忆带，填充槽与空槽均不使用完整四边框。
4. **无框分页**：箭头进入内容两侧的独立沟槽，禁止覆盖槽位；页码恢复为纯文字和短光痕。
5. **双流程图**：蓝、红两张流程图拥有不同节点和拓扑，只使用直线与直角分支。流程图在原位扩充为全屏，右侧才出现场景纸片；不设置中央分割线。
6. **流程交互**：全屏流程图隐藏原生滚动条，可使用滚轮、键盘和鼠标拖拽纵向移动；最右侧仅显示一条细进度痕。两张图分别保留选中节点和滚动位置。
7. **故事与日记**：STORY 使用贯穿竖线、场景图和文字列，不再堆叠矩形卡片；DIARY 使用巨型月份数字、斜切渐隐图片和左下文字的一月一面构图。
8. **转场与可访问性**：轨道、二级分类和月份切换继续使用旧新内容交叠淡入淡出；键盘可操作主/次导航、流程图和滚动条，并尊重 `prefers-reduced-motion`。

## 后续

- XI 与 X 并排评估后，再决定哪套视觉语言进入最终版本。
- 故事游玩和日记 NVL 阅读仍是后续独立实施范围。
