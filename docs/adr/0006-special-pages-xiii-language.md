# ADR 0006：特殊页面继承 LOAD ⅩⅢ 的系统语言

日期：2026-07-28

状态：已确认并实施

## 背景

LOAD ⅩⅢ 已经确定为整站特殊界面的视觉基线，但 START、EXTRA、OPTION、文章 PAGE、EXIT 与 404 仍停留在原型阶段。直接复制 LOAD 的双栏布局会抹平各页面的用途；完全独立设计又会重新产生字体、按钮、返回和转场不一致的问题。

## 决策

1. **共享系统语言而非共享页面骨架**：特殊页面统一使用 LOAD ⅩⅢ 的场景自适应色彩、独立游戏按钮、返回行为、衬线标题与短促确认反馈；内容布局按页面用途独立设计。
2. **拒绝网页面板堆叠**：不以细线方框、Dashboard 卡片、渐变扫光或重复小标题制造层级。槽位和控制主要依靠面积、明暗、字重、位置与短促运动建立关系。
3. **START 使用 ADV 接待布局**：角色、台词与选择负责关于我、状态、更新和随机文章等叙事入口；需要快速访问的内容仍提供直接链接。
4. **EXTRA 使用鉴赏室布局**：第一版固定为 `CG / MUSIC / CHARACTER / PROJECT / BANGUMI / DEVELOPMENT`，每类拥有自己的内部构图，不强套同一网格。
5. **OPTION 使用系统设定布局**：分类入口沿用独立游戏按钮；设定值真实写入本地偏好，并至少驱动特殊鼠标指针、界面文字比例、天气密度、场景渐变、暗角和减少动态效果。
6. **PAGE 使用阅读画卷布局**：外层保留场景与系统按钮，正文保持 720–840px 的长文阅读宽度；桌面提供窄目录，结尾使用上一篇/下一篇读取记录，不使用推荐卡片墙。
7. **404 与 EXIT 完全游戏化**：404 使用 ADV 丢失路线演出；EXIT 使用底部选择层，不使用居中的网页模态卡片。
8. **统一转场**：站内鼠标导航采用可中断的 200–300ms `transform/opacity` 过渡；LOAD 进入文章时使用连续的 `NOW LOADING` 遮罩；键盘导航不播放位移动画；所有页面尊重 reduced-motion。
9. **数据与演出分离**：START 与 EXTRA 的内容数据独立于渲染控制器，后续可由真实友链、Bangumi、项目和状态数据替换。

## 验收

- 四种场景下特殊页面的导航和必要文字均可辨认。
- EXTRA 六个分类均有可操作内容，CG 可全屏查看，外链是真实链接。
- OPTION 刷新后保留设置，特殊鼠标指针可开关。
- PAGE 有目录、阅读位置保存、上一篇/下一篇与顺滑进入/离开转场。
- 404、EXIT 和 START 在不阅读说明文字时也能被理解为视觉小说界面。
- 桌面与窄屏均无内容重叠，并通过 reduced-motion 验证。

## 实施结果

- START、EXTRA、OPTION、PAGE、404 与 EXIT 均已迁入同一体验系统，同时保留各自构图。
- EXTRA 的 MUSIC 使用浏览器实时合成的低音量预览，可播放、暂停、切曲并在离页时停止；后续仍可直接替换为正式音源。
- 系统页面支持桌面、短屏横向与手机竖向布局；LOAD XIII 在竖屏下改用纵向存档列表，并保留日期与剧情进度。
