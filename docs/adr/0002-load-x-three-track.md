# ADR 0002：LOAD X 三轨读取界面

日期：2026-07-24  
状态：已确认并实施  
取代：ADR 0001

## 背景

Ⅰ–Ⅸ 的对比已经证明，仅替换卡片样式无法得到理想的视觉小说读档体验。新的 X 方案需要先建立稳定的信息结构，再分别承载文章、可游玩的故事记录和 NVL 日记。

## 决策

1. **保留参考方案**：Ⅰ–Ⅸ 继续作为临时视觉参考，X 作为当前实施方案；切换器暂不删除。
2. **三条读取轨道**：顶部固定为 `ARTICLES / GAME DATA / DIARY`。二级分类常驻左侧，只显示英文选项，不重复主标题或说明文字。
3. **文章记录**：槽位只显示封面、标题和日期；分类由左侧索引表达，不再重复星期、分类角标或 `LAST LOAD`。每页六槽，空位与分页继续显示。
4. **游戏记录**：二级分类为 `SAVE DATA / FLOWCHART / STORY`，删除 `MEMORY`。流程图在普通界面显示缩略结构，原位扩充为全屏后才显示场景详情；故事页使用左图、标题、简述和锁定槽位。
5. **日记记录**：左侧按年份切换，右侧每页显示一个月份及其图片与摘要；每日内容留给后续 NVL 阅读模式。
6. **转场**：鼠标触发的主轨、二级分类和分页切换使用快速的旧新内容交叠淡入淡出；键盘触发不播放位移动效，并尊重 `prefers-reduced-motion`。
7. **视觉边界**：沿用 V4 的 16:9 体验壳与场景配色。X 不显示键位提示、重复标题或中英混排的小型说明；Ⅰ–Ⅸ 的既有展示不在本次重构范围内。

## 后续

- 当 X 定稿后，再单独决定是否删除参考切换器和落选方案。
- 进入日记或故事后的 NVL/ADV 游玩方式另立决策，不在本 ADR 范围内。
