# ADR 0005：LOAD XIII 以 X 为结构母版重做

日期：2026-07-27

状态：已确认并实施

取代：ADR 0004

## 背景

XI–XIII 的连续调整放大了连体选择器、网页式细线槽位、过强索引高亮与突兀流程图详情等问题。XIII 不再延续这些视觉，而回到 X 已确认的页面结构，并重新建立更接近 Galgame 读取界面的内容表现。

## 决策

1. **版本并存**：Ⅰ–Ⅻ全部保留，XIII 使用独立组件、样式与控制器。
2. **独立页面入口**：`ARTICLES / GAME DATA / DIARY` 是三个各自完整的游戏按钮，不使用共同底板、外框或分段选择器语义。
3. **统一公共界面**：页面入口、无图标的左侧页内索引、返回与翻页控制共享同一视觉语言；内容区按用途分别构图。
4. **不同记录槽**：文章采用封面主导的六槽读取记录；玩家存档采用 CG、章节、进度与存档时间组成的传统六槽存档，并恢复四页演示分页。
5. **流程图原位展开**：FLOWCHART 在当前对象的位置连续扩展为全屏流程；右侧场景详情在扩展后渐入，收起时回到原布局。
6. **故事场景列**：STORY 使用无分支信息的一列场景槽，包含画面、标题、简介与锁定槽；点击已解锁场景进入游戏确认层。
7. **月度日记画面**：DIARY 左侧选择年份，内容区一月一面并提供演示月份；点击月份进入 NVL 阅读预览，不在 LOAD 内拆分日期。
8. **内容级动效**：页面与分类使用新旧内容叠加的快速淡入淡出；文章、存档和月份翻页只横移内容区。键盘操作即时切换，并尊重 `prefers-reduced-motion`。
9. **四场景可读性**：灰霭、晴天、暗夜与赤夜均使用场景自适应色彩，保证公共 UI 和必要信息可辨认。

## 后续

- 用真实游戏场景、流程分支、玩家存档与日记内容替换演示数据。
- 在统一音频系统完成后消费现有 `lonely-sea:ui-cue` 事件。
