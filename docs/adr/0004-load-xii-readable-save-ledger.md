# ADR 0004：LOAD XII 月海存档

日期：2026-07-25  
状态：已确认并实施  
取代：ADR 0003

## 背景

XI 的氛围比 X 更统一，但主导航、侧栏、存档信息与分页过小、过淡；文章和游戏记录不像实际存档槽。FLOWCHART 的密度、可读性和交互也没有达到《月姬 Remake》式流程图的要求，STORY 还错误地沿用了侧栏式竖线与选中标记。

## 决策

1. **版本并存**：Ⅰ–XI 全部保留，XII 使用独立组件、样式和控制器，并成为默认对照版本。
2. **游戏主选择器**：`ARTICLES / GAME DATA / DIARY` 居中组合为一个有端帽、分段和按压反馈的游戏界面部件；点击统一派发音效事件，供后续接入清脆 UI 音。
3. **窄而清楚的侧栏**：侧栏收窄，文字增大；选中标记改为依附竖线的潮痕缺口，不再使用孤立菱形。
4. **真实存档槽**：文章与游戏记录统一使用双列六槽的读档结构，固定包含清楚的编号、16:9 图像、标题和必要日期或进度；分类不在槽位重复，空槽明确显示 `EMPTY DATA`。
5. **方向翻页**：鼠标触发的文章与月份翻页使用旧页和新页重叠的横向滑入滑出；键盘翻页保持即时响应，并尊重 `prefers-reduced-motion`。
6. **重建流程图**：蓝、红流程采用紧凑的直角拓扑、章节横界和可辨认缩略图。缩小状态即可滚轮、拖拽与选择节点；原位扩充后才显示右侧场景说明，滚动进度保持在最右侧。
7. **故事进入逻辑**：STORY 不再使用竖线或菱形，改为独立场景记录列；点击已解锁场景弹出 `ENTER THIS STORY?` 游戏确认层，并派发后续游戏入口事件。
8. **月份画卷**：DIARY 使用连续画面拆成三片的月度画卷，一年为左侧分类、一月一页；点击后进入现有 NVL 阅读预览。

## 事件接口

- `lonely-sea:ui-cue`：主选择、翻页、打开、返回等 UI 音效钩子。
- `lonely-sea:story-enter`：确认进入故事后的游戏入口钩子。
- `lonely-sea:save-select`：选择游戏存档后的入口钩子。
